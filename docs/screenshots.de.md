# Screenshots

Echte Aufnahmen aus einer laufenden Home Assistant, jede im hellen und im dunklen Modus. Die Werte stammen aus einem Haushalt (mehrere PV-Quellen, vier Batterien, ein Charger und fünfzehn Einzelgeräte); die Einzelgeräte nutzen `display_zero: true`, damit auch ruhende Geräte erscheinen.
